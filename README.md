# Патанатомия — Telegram-бот курса

Telegram-бот и Mini App для удобного доступа к материалам курса по патологической анатомии.

В приложении материалы собраны по разделам и доступны прямо внутри Telegram: можно читать конспекты, просматривать изображения и быстро переходить между темами.

## Возможности

- материалы курса по разделам;
- тексты и медицинские изображения;
- удобная навигация по темам;
- доступ к материалам по подписке;
- информация о сроке доступа.

## Стек

- Python
- Telegram Bot + Mini App
- SQLite
- YooKassa
- Nginx
