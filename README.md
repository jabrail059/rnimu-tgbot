# Патанатомия: Telegram bot + Mini App

Подписка стоит 120 ₽ за 30 календарных дней. Бот использует кошелёк ЮMoney и HTTP-уведомление о платеже; Mini App получает материалы только после серверной проверки подписанной Telegram `initData`.

## Запуск

1. Скопируйте `.env.example` в `.env`, внесите токен бота, публичный HTTPS-адрес и номер кошелька.
2. В настройках кошелька ЮMoney включите HTTP-уведомления и укажите `https://ваш-домен/api/yoomoney/notification`. Секретное слово сохраните в `YOOMONEY_NOTIFICATION_SECRET`.
3. Укажите Mini App URL в BotFather либо запустите приложение и откройте `/start`: кнопка уже получает адрес из `PUBLIC_BASE_URL`.
4. Установите зависимости и запустите:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```

Для разработки нужен HTTPS-туннель; Telegram Mini Apps и уведомления ЮMoney должны обращаться к публичному HTTPS URL.

## Контент

Темы и текст находятся в `app/content.py`. Это серверный контент: браузер не получает весь набор материалов заранее.

## Реальная защита

Web-приложение не может запретить системные скриншоты, запись экрана или фото экрана. Поэтому здесь сделаны проверка подписки на каждом запросе, проверка Telegram `initData`, отсутствие публичных URL материалов и базовое отключение выделения/контекстного меню. Это снижает случайное копирование, но не является DRM.
